# kod_asistanim
proje yazarı: Muhammed Ali Bozyiğit

#projenin adı: kod asistan v0.1

##projenin amacı: kullanıcılara günlük 
işlerinde(hesaplama,selamlama vb) yardımcı olacak bir dijital asistan tasarlamak.

##projenin hedefleri: asistanı geliştirerek, hatalarını fixleyerek, v1.0 yapmak

##projenin kapsamı: kritik eşik sözde kodu; 
adım 1 başla 
adım 2 saat = 1
adım 3 su seviyesini al (SS)
adım 4 eğer SS<50 ise "güvenli durum kapaklar kapalı" yaz, saat+=1, adım 3 e git
adım 5 değilse "acil durum tahliye edin, kapaklar açıldı yaz"
adım 6 bitir
